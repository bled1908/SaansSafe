# SaansSafe

**Air-quality safety decisions for schools.** SaansSafe helps school principals and PE teachers decide when outdoor activities are safe for children. It turns the Indian AQI and its hourly forecast into a clear plan for the school day.

Built for **Environmental Hacks** (Bharat Builds Tour, WeMakeDevs × AWS, Oct 8–11 2026), Air track.

> 🚧 Work in progress. Features, the live URL, the architecture diagram and setup instructions will be added as they are built.

## Status

- [ ] Backend walking skeleton on AWS (SAM, Lambda, API Gateway, DynamoDB)
- [ ] Indian AQI (CPCB method) calculated from forecast data
- [ ] Web app showing current AQI
